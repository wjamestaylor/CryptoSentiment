## Quick Start

### 1. Sign Up & Sign In
- Create an account using Google OAuth or email authentication
- After signing in, you'll see a welcome tour explaining the platform's key features

### 2. Add Your First Cryptocurrency
1. Navigate to the **Dashboard** or **Crypto** page
2. Click "Add Crypto" or "Browse Cryptos"
3. Search for a cryptocurrency (e.g., "bitcoin", "ethereum")
4. Choose to either:
   - **Watch** - Track prices and sentiment without adding holdings
   - **Hold** - Add your actual holdings with purchase details

### 3. Get AI Insights
1. Go to the **Sentiment** page
2. Enter a cryptocurrency name (e.g., "bitcoin")
3. Click "Analyze" to get AI-powered sentiment analysis
4. Review the sentiment score, confidence level, and key factors

### 4. Set Up Alerts
1. Navigate to the **Alerts** page
2. Click "Create Alert"
3. Choose alert type:
   - **Price Alert** - Notify when price reaches a target
   - **Sentiment Alert** - Track market mood changes
   - **Volume Alert** - Monitor unusual trading activity
4. Configure conditions and save

## Core Features

### 📊 Dashboard
Your central hub for monitoring all tracked cryptocurrencies.

**What you'll see:**
- Portfolio value and 24h change

- Price charts for your top performer

### 🤖 AI Sentiment Analysis
Get data-driven insights powered by advanced AI models.

**How it works:**
1. AI analyzes multiple data sources:
   - Market price movements
   - Trading volume patterns
   - News sentiment
   - Social media trends
2. Generates a sentiment score (0-100):
   - **60-100**: Bullish 📈
   - **40-60**: Neutral ➡️
   - **0-40**: Bearish 📉
3. Provides confidence level and key factors

**Best practices:**
- Use AI analysis as ONE factor in your decision-making
- Higher confidence scores are more reliable
- Review the "key factors" to understand the reasoning
- Compare sentiment across multiple cryptocurrencies

## Understanding Sentiment Analysis

### Sentiment Scores Explained

**Score Range:** 0-100
- **80-100:** Very Bullish - Strong positive sentiment
- **60-79:** Bullish - Positive sentiment trend
- **40-59:** Neutral - Balanced market sentiment
- **20-39:** Bearish - Negative sentiment trend
- **0-19:** Very Bearish - Strong negative sentiment

### Confidence Levels

**Confidence:** 0-100%
- **80-100%:** High confidence - Multiple data sources agree
- **60-79%:** Moderate confidence - Most indicators align
- **40-59%:** Low confidence - Mixed signals
- **Below 40%:** Very low confidence - Conflicting data

**When to trust the analysis:**
- High confidence (80%+) with multiple supporting factors
- Consistent with recent price trends
- Aligned with major news events

**When to be cautious:**
- Low confidence (<60%)
- Single data source
- Contradicts strong technical indicators

## Setting Up Alerts

### Using the Alert Wizard (Recommended)

Our step-by-step wizard makes alert creation easy:

**Step 1: Select Cryptocurrency**
- Enter the crypto symbol (e.g., btc, eth, sol)
- Optionally add the full name

**Step 2: Choose Alert Type**
- Review examples for each type
- Select the one that matches your needs

**Step 3: Set Conditions**
- Configure thresholds and triggers
- Use tooltips for guidance on each field

**Step 4: Review & Create**
- Verify your alert settings
- Click "Create Alert" to activate

### Alert Best Practices

1. **Start with price alerts** - Easiest to understand and most reliable
2. **Set realistic targets** - Avoid overly optimistic or pessimistic thresholds
3. **Use multiple alert types** - Combine price, sentiment, and volume for comprehensive monitoring
4. **Review regularly** - Edit or disable alerts that no longer serve your strategy
5. **Don't over-alert** - Too many notifications can lead to alert fatigue

## Tips & Best Practices

### For New Users

1. **Start Small**
   - Add 3-5 cryptocurrencies to your watchlist
   - Run AI analysis on each to understand the insights
   - Set up 1-2 price alerts for practice

2. **Explore Features Gradually**
   - Week 1: Watchlist and Dashboard
   - Week 2: AI Sentiment Analysis
   - Week 3: Alert System
   - Week 4: Portfolio Tracking

3. **Use the Help Tooltips**
   - Look for the ⓘ icon throughout the app
   - Hover for quick explanations
   - No need to leave the page

### For Active Traders

1. **Leverage AI Analysis**
   - Analyze before major trades
   - Compare sentiment across similar assets
   - Track confidence trends over time

2. **Set Strategic Alerts**
   - Price alerts at key support/resistance levels
   - Sentiment alerts for trend changes
   - Volume alerts for breakout detection

3. **Monitor Your Dashboard**
   - Check daily for portfolio updates
   - Review alert history for patterns
   - Adjust watchlist based on market conditions

### For Long-Term Investors

1. **Focus on Portfolio Tracking**
   - Add all holdings with accurate purchase data
   - Monitor long-term performance trends
   - Use analytics for rebalancing decisions

2. **Use Conservative Alerts**
   - Set price alerts for significant moves (±20-30%)
   - Track sentiment shifts over weeks, not days
   - Focus on volume for major market events

3. **Analyze Periodically**
   - Run AI analysis monthly or quarterly
   - Look for major sentiment shifts
   - Adjust holdings based on conviction changes
